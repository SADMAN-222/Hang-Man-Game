# Hangman Game 🎮

This is a **CSE103 Structured Programming** course project — a terminal-based **Hangman Game** developed in C.

## 🧑‍💻 Developers

- Md. Sadman Ahmmed Chowdhuri
- Nawreen Islam

## 📌 Description

This is a simple word-guessing game where players try to guess the correct word by suggesting letters within a limited number of attempts. The game includes:

- Multiple **categories**: Fish, Animal, Bird, Food
- Two **difficulty levels**: Easy (6-letter words), Medium (7-letter words)
- A graphical **ASCII Hangman** that updates with each wrong guess

The game randomly selects words from a `words.txt` file and challenges the player to guess them before the hangman is fully drawn.

## 🛠️ Features

- Random word selection by category and difficulty
- Command-line interface
- ASCII art for hangman figure
- Replay functionality
